About the Project
This project is a personal endeavor to replicate the core functionalities and user interface of Google's Gemini AI. The goal is to understand the underlying principles of AI conversational models and web development by building a simplified version from scratch.

This clone aims to provide a similar user experience to the actual Gemini, focusing on key aspects such as:

Interactive chat interface: Sending queries and receiving AI responses.
Response generation: Simulating AI-like output based on predefined or simple logic.
Clean and responsive UI: Mimicking Gemini's aesthetic and usability.
